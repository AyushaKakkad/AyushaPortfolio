Academic Project

Sustainable Energy Forecasting

Applying machine learning and regression techniques to forecast hourly electricity consumption.

Project Overview

Developed machine-learning forecasting models to predict hourly electricity consumption using a time-series electricity consumption dataset. Applied data preprocessing, feature engineering and regression techniques to analyse consumption patterns and forecast electricity demand.

My Contributions

  • Preprocessed electricity consumption data and prepared training and testing datasets.
  • Performed feature engineering using temporal variables such as year, quarter, month, week, day and hour.
  • Explored relationships between electricity consumption and environmental factors, including temperature, pressure and wind speed.
  • Developed hourly electricity consumption forecasting models using XGBoost, Random Forest and Linear Regression.
  • Evaluated and compared model performance using RMSE and R² metrics.

Models and Techniques

  • XGBoost Regressor
  • Random Forest Regressor
  • Linear Regression
  • Time-based feature engineering
  • Chronological training and testing split

Tools and Technologies

  • Programming: Python
  • Data Processing: Pandas, NumPy
  • Machine Learning: Scikit-learn, XGBoost
  • Visualisation: Matplotlib, Seaborn

Project Outcome

Applied machine-learning forecasting techniques to predict hourly electricity consumption and evaluate predictive performance using regression evaluation metrics.
